# ATS Resume Builder

An ATS (Applicant Tracking System) Resume Builder application designed to help users create professional, ATS-friendly resumes. This project consists of a frontend built using React and a backend powered by Python. The application allows users to input their details, preview resumes in real time, and generate structured resumes optimized for job applications.

---

## Features

- User-friendly resume form interface  
- Generates ATS-optimized resumes  
- Clean and responsive user interface  
- Real-time resume preview  
- Download resume in structured format  
- Backend integration for processing data  
- Proper formatting for applicant tracking systems  

---
